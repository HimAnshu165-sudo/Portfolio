# Himanshu Sharma — Creative Developer Portfolio

> **Cinematic, high-fidelity portfolio built with Next.js 15, Three.js, React Three Fiber, GSAP, and Tailwind CSS.**

---

## 🌟 Highlights

- **Scroll-Driven Canvas Experience**: 240 high-resolution cinematic frames scrubbed dynamically with GSAP ScrollTrigger.
- **Signature Kick Impact**: Dynamic WebGL shockwave, screen recoil, and chromatic dispersion transition triggered at frame 205.
- **Elastic Project Rows**: Physics-driven Framer Motion hover stretch revealing deep project previews for 10 live shipped projects.
- **The 3D Lab**: Interactive Three.js spatial ecosystem with category filters (`Creative & WebGL`, `Frontend & Full-Stack`, `Backend & Database`, `Motion & Performance`).
- **Capabilities Matrix**: Comprehensive breakdown across Design, Engineering, Motion, and Production Deployment.
- **Editorial Character Profile**: "Behind The Screen" section featuring authentic photography and kinetic typographic metrics.
- **Production Performance**: Lenis smooth scroll, responsive WebGL DPR clamping, and zero-flicker dynamic asset loading.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, React 19, TypeScript)
- **3D & WebGL**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber), [@react-three/drei](https://github.com/pmndrs/drei)
- **Choreography & Motion**: [GSAP](https://greensock.com/gsap/), [ScrollTrigger](https://greensock.com/scrolltrigger/), [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [@studio-freight/lenis](https://github.com/darkroomengineering/lenis)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/HimAnshu165-sudo/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the experience.
